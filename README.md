# Repo Agent Kit

Free, browser-local tools for repositories that use coding agents.

[Open Repo Agent Kit](https://repoagentkit.com/?utm_source=github-product-repo&utm_medium=repository&utm_campaign=repoagentkit)

## Start with one useful result

- [Audit a public GitHub repository](https://repoagentkit.com/github-repo-audit?utm_source=github-product-repo&utm_medium=repository&utm_campaign=repoagentkit&utm_content=github-audit)
- [Check an AGENTS.md or CLAUDE.md file](https://repoagentkit.com/audit?utm_source=github-product-repo&utm_medium=repository&utm_campaign=repoagentkit&utm_content=file-checker)

- [Explore AGENTS.md adoption across 100 popular repositories](https://repoagentkit.com/agents-md-adoption?utm_source=github-product-repo&utm_medium=repository&utm_campaign=repoagentkit&utm_content=adoption-report)

## Installable tools

- [`gh-agents-md`](https://github.com/sunxiayi/gh-agents-md) — GitHub CLI extension for creating, auditing, and generating agent instructions
- [`agents-md-starter-kit`](https://github.com/sunxiayi/agents-md-starter-kit) — copy-ready templates, reusable agent skills, and a GitHub Action
- [`repo-agent-instruction-security-scan`](https://github.com/sunxiayi/repo-agent-instruction-security-scan) — zero-dependency CLI, pre-commit hook, and GitHub Action
- [`agents-md-adoption-dataset`](https://github.com/sunxiayi/agents-md-adoption-dataset) — commit-pinned adoption and configuration-smell data

## Privacy and scope

File checks, conversions, and generators run in the browser. Public-repository tools read GitHub's public API directly from the visitor's browser. Repo Agent Kit does not proxy or store repository names, query strings, fetched file contents, or uploaded files.

Results are deterministic review aids, not guarantees that a repository is correct, secure, or ready for every coding agent.
