# Repository guidance

This is the public project home and issue tracker for Repo Agent Kit. The hosted website source is maintained separately.

## Changes

- Keep links factual and point product actions to `https://repoagentkit.com`.
- Preserve the privacy and scope boundaries in `README.md`.
- Do not add private repository content, credentials, tracking identifiers tied to a person, or unverifiable product claims.
- Keep documentation concise and validate Markdown changes with `git diff --check`.

## Boundaries

- Do not claim that a clean scan proves a repository is secure.
- Do not manufacture traffic, stars, issues, or other engagement.
- Do not mirror hosted application source or deployment credentials into this repository.
